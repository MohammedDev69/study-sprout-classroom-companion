# Study Sprout Classroom Companion

Create a fully responsive, modern, and production-ready educational platform web application optimized for both desktop and mobile devices. 

### 🎨 Design & UI/UX:

- **Color Palette:** A professional, sleek blue theme using deep navy blue (`#0F172A` or `#1E3A8A`) for headers/sidebars, vibrant royal blue (`#2563EB`) for primary buttons and active states, and soft ice-blue (`#EFF6FF` or `#DBEAFE`) for backgrounds and cards.

- **Interface:** Clean, minimalist, and student-friendly dashboard layout with smooth transitions, modern card components, and clear visual hierarchy.

### 📚 Core Features & Structure:

1. **Content & Solutions Hub:**

   - Categorized sections by subjects/courses.

   - Detailed pages for explanations, study materials, and step-by-step problem solutions.

2. **Schedules & Timetable:**

   - An interactive calendar/schedule view for upcoming classes, lectures, study sessions, and deadlines.

3. **Advanced Quiz System:**

   - Supports multiple question types: Multiple Choice Questions (MCQ), True/False, Fill-in-the-blanks, and Short Essays.

   - Interactive timer, instant score calculation, and detailed review of correct/incorrect answers upon submission.

### 📱 PWA (Progressive Web App) & Mobile Capabilities:

- **Installable App:** Configure the project as a Progressive Web App (PWA) with a `manifest.json` and service worker so users can easily "Add to Home Screen" and install it as a native application on their smartphones.

- **Push Notifications Integration:** Include a simulated or Web Push API integration framework for sending timely notifications and alerts to students (e.g., reminding them about upcoming quizzes, new study materials, or schedule updates).

### 🛠️ Technical Stack Preferences:

- React / Next.js (or Vite + React) with Tailwind CSS for styling and Lucide React for clean icons.

- Fully functional components with mock data pre-filled so the UI looks active and alive right out of the box.
